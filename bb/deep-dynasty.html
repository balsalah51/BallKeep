Deep Dynasty Baseball Board

A Deep Dynasty baseball board aggregates hundreds of players - major leaguers, top prospects, and minor leaguers - the same way the football boards aggregate expert rankings. We audited every candidate source for this board in November 2026. Result: only 3 independently sourced deep dynasty boards are publicly and legally accessible. The minimum to publish is 5. The board is not yet live.

The 3 confirmed boards power the existing The Keep aggregate. They are genuinely deep (500-591 players each, including top prospects). What's missing is additional distinct expert boards that rank the full universe of dynasty players - veterans plus the minor-league pipeline - in a machine-readable format.

What Would Unlock This Board

The highest-value additions would be:

  • KeepTradeCut Baseball - KTC is the gold standard for dynasty trade values in NFL and has deep basketball; a baseball equivalent with 1,000+ players would immediately count as a primary source.
  • FanGraphs The Board / Steamer - FG publishes both FV grades and Steamer/ZiPS projections for the full minor league pipeline. A public CSV API would add 1-2 boards instantly.
  • RotoWire Dynasty Top 500 - RotoWire titles their page "Top 500 Prospects" which suggests full pipeline coverage, but the data requires JavaScript rendering. A static endpoint or data license would add this.
  • Four-Seam Fantasy (Martin Sekulski) - The Dynasty 600 list is exactly the right depth. Requesting the author's permission to scrape and attribute the rankings is likely the easiest path to a 4th board.
  • Dynasty League Baseball - If DLB publishes a public rankings page, it would add a platform-native deep dynasty signal.

Once 5 or more of the above are confirmed accessible and attributed, this page will be replaced by the live board with player search and filters (position, MLB team, minors vs. majors, age). The board will display the true source count - not 40.
