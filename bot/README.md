# Ball Keep Discord bot

The desk, in a server. The bot loads `data/discord-catalog.json` (built from the site) so Discord can search player rankings, run the four trade calculators, drop highlight videos, and — with `/publish` — write the entire Ball Keep site into channels.

Powder-blue ranks. Red ink. Nicknames, spoilers, and a theatrical keep-or-cut button.

## What it can do

| Command | What happens |
|---|---|
| `/desk` | Tour of the bot |
| `/player Josh Allen` | Keep rank, BK Value, plus/minus, age, college, tape, site link |
| `/search jsn` | Fuzzy + nicknames (JSN, CMC, Sun God, BTJ, TLaw, MHJ…) |
| `/rank` `/top` `/pos` | Any list: Keep, Board, PPR, Standard, Rookies — or just the QBs |
| `/trade` | Superflex / 1QB / PPR / Standard calculator |
| `/deals JSN` | Recent packages involving a player (same tape as the site) |
| `/value` `/picks` `/formula` | One name, every future pick, or the decaying curve itself |
| `/video` | 2025 NFL or college clip from the player page |
| `/hot` `/cold` `/hottake` `/rookies` | Market tape, a random buy/sell, the 2026 class |
| `/compare` `/keep-or-cut` `/start` `/quiz` `/random` `/stack` | Fun desk tools |
| `/nfl` `/mlb` | Full 2026 NFL slate and September baseball (`bills`, `yankees` work) |
| `/bbplayer` `/bbkeep` `/bbtrade` `/bbwire` | BaseBallKeep files, boards, calculator, and waiver wires |
| `/plplayer` `/pitch` `/pltrade` | PitchKeep files, The Pitch 250, and Premier League trade calculator |
| `/sources` | The ten Superflex boards inside The Keep |
| `/publish` | **Admin.** Creates a **BALL KEEP DESK** category and posts every list, every player file, every clip, every NFL week, and the September MLB slate so native Discord search works |
| `/reload` | Admin. Reload the catalog after a site rebuild |
| `!bk player maye` | Prefix alias (`!bk video`, `!bk trade Allen vs Bijan`, `!bk top keep`) |
| `who is Drake Maye` | Natural-language lookup. Also: `trade Allen for Bijan`, `start Gibbs or Jeanty`, `video jsn` |

Trade example:

```
/trade Superflex Dynasty
side_a: Josh Allen, 2027 Mid 1st
side_b: Bijan Robinson, Ja'Marr Chase
```

Same curve as [ballkeep.com/trade.html](https://ballkeep.com/trade.html). Fair is within 8%. Pick shorthand like `27 mid 1st` works.

## Run it

1. Rebuild the site catalog (from the repo root):

```bash
python3 scripts/build_site.py
```

2. Create an application at [Discord Developer Portal](https://discord.com/developers/applications) → Bot → Reset Token.

3. Privileged intent: **Message Content Intent** on (for `who is …` and `!bk` prefix). Slash commands work without it.

4. OAuth2 → URL Generator → scopes `bot` + `applications.commands`. Permissions:

   - Send Messages, Embed Links, Attach Files, Read Message History
   - **Manage Channels** (only needed for `/publish`)

5. Invite the bot to your server.

6. Copy `bot/.env.example` to `bot/.env` (or the repo-root `.env`) and paste the token. Optionally set `DISCORD_GUILD_ID` so slash commands appear immediately in that server.

```bash
python3 -m pip install -r bot/requirements.txt
python3 bot/bot.py
```

7. In Discord: `/desk` then `/publish` once. It takes a few minutes — Discord rate-limits channel posts — and writes The Keep, The Board, redraft, rookies, Hot/Cold, pick values, tape, every NFL week, September MLB, the ten Superflex sources, and every player file.

## Data

`data/discord-catalog.json` is generated by `scripts/build_site.py`. After you change rankings, rebuild the site, then `/reload` or restart the bot.

Smoke-test without Discord:

```bash
python3 bot/test_catalog.py
```
